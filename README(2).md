# BIOSENS Skills Landscape

Streamlit dashboard comparing skill lists for 2019 and 2025 across five geographies and 20 industries.

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run BIOSENS_skills_dashboard.py
```

## Deploy on Streamlit Community Cloud

Upload the three files in this repository root. At share.streamlit.io, create an app from the GitHub repository and set the main file to `BIOSENS_skills_dashboard.py`.

The workbook filename is read verbatim from this folder. Commit an updated workbook under the same name to refresh the dashboard.
